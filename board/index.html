How to drive it

Drag a card between columns, or press ← → while it has focus. Click the P1 badge — or press 1–5 on a focused card — to set priority; cards sort P1 first inside every column. Tick items off as you go: when the last one is ticked the card moves itself to Shipped, and unticking sends it back where it came from. Click an item's text to reword it, × to delete it, + item to add one. Enter or a double-click rewrites a title. + Card adds one, × removes it. Everything stays in your browser for now — your ticks are not visible to anyone else opening this link. Reset restores the last sync.
Heads up: this view isn't allowed to store anything, so moves reset on reload.

Adding work from Slack

React to any Slack message with :todo: and it lands in the To do column at the next sync, with a link straight back to the thread. Nothing to fill in — the reaction is the capture. Un-react to drop it again. When anyone adds a ✅ to that same message it counts as finished, so the card arrives already ticked and sitting in Shipped.

Not wired up yet: nothing is polling Slack on a timer, so for now these appear when the board is rebuilt by hand. The 5-minute job is the next piece.
